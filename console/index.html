光传感器标定向导 · 第二阶段

从 USB 串口或 Wi‑Fi 调试页启动自动向导。设备开机并保持低速后，软件按低 → 中 → 高 → 自动逐档采样，最后提示关机采集暗态；不会控制光耦或写入设备配置。

操作顺序
  1. 安装好 PCB，开机并调到低速，点击“开始自动标定”。
  2. 低速自动采样约 3 秒；随后按一次实体风速键切到中速。
  3. 每次切档后软件自动采样约 3 秒，再提示切到下一档。
  4. 完成自动档后按电源键关机，等待四盏灯稳定熄灭并导出报告。

MQTT 并发压力测试

生成临时虚拟设备遥测，测量 Broker 接受速率。消息只进入 air/loadtest/v1，不会进入真实设备目录，也不会发送控制命令或保留消息。

30 台 × 20 Hz 相当于每秒约 600 条遥测消息。超过每秒 1200 条或超过 60 秒属于高负载，开始前会再次确认；越界参数将直接拒绝，不会悄悄改成别的数值。
