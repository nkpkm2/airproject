# 设备目录与分组

控制台只有一个设备目录，板卡 Wi-Fi 调试和家庭总览都从本机控制服务读取它，不再各自保存一套设备名称或房间。

## 自动发现

- 固件以不可变设备 ID 发布 MQTT 消息。
- 本机服务第一次看到设备时自动建立目录记录；界面不提供“手工添加设备”。
- 删除设备的含义是从目录隐藏，不会向板卡发送删除命令。
- 被隐藏的设备在下一次真实上线并发布 `availability=online` 时自动重新出现。

## 资料与分类

每台设备保留不可变设备 ID，并可设置设备别名、净化器编号、唯一所属房间和多个自定义分组。房间分类是单层的“家庭 / 房间 / 设备”；自定义分组允许任意层级的父子文件夹。

目录持久化在 `control-service/data/device_catalog.json`。该运行数据不进入 Git；首次启动时自动建立。

## 状态灯

- 绿色：最近 3 秒内收到心跳，在线。
- 黄色：超过 3 秒没有心跳，暂时无响应。
- 红色：超过 5 秒没有心跳，离线。

界面每秒刷新状态，但只在设备、资料或分类发生变化时重绘目录，从而保留文件夹开合、滚动位置和当前选择。
