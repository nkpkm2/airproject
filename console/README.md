# 空气净化器调试台

这是一个本机运行的图形化调试台。它使用浏览器的 Web Serial 功能直接连接 ESP32-C3 的 USB 串口，因此无需 MQTT 服务即可读取现有板子的 `info`、`scan` 日志，并执行 LED、ADC 和光耦测试。

## 启动

在项目根目录运行：

```powershell
& 'C:\Users\CHJ\AppData\Local\Programs\Python\Python312\python.exe' -m http.server 8765 --directory console
```

使用 Chrome 或 Edge 打开 [http://localhost:8765](http://localhost:8765)。点击“连接 USB 串口”，在系统选择器中选择 COM6 对应的 ESP32-C3。浏览器会请求串口授权；这是 Web Serial 的安全要求。

统一入口是 `http://localhost:8765/index.html`。家庭总览、串口调试和 Wi‑Fi 调试作为长期存活的工作区嵌入同一个经典桌面外壳，切换工作区不会销毁另一个页面的串口或远程会话。

## 当前可用能力

- 管理设备不可变 ID（MAC）、可变别名、净化器编号、房间和自定义分组；目录数据由本机服务持久化；
- 从已连接的开发板读取芯片、Flash、内存和 Wi-Fi 扫描信息；
- 固件上电后自动连接固定的 2.4 GHz 家庭网络，并通过 MQTT 自动发现；
- 显示已连接网络的实际 RSSI、IP 地址和线性信号刻度，并保留扫描到的网络列表；
- 发送 `info`、`scan`、`blink` 和 `reboot` 自检命令；
- 显示四路 ADC 和两路光耦的串口与 Wi‑Fi 调试面板；
- “诊断工具 → 光传感器标定向导”可从 USB 或 Wi‑Fi 先完整记录四路原始 ADC，再自动识别关机暗态、稳定平台、启动闪烁和每路独立阈值，导出原始 CSV/JSON 与分析报告；本阶段不会控制光耦、改变模式或写入标定阈值，详见 [`docs/light-sensor-calibration.md`](../docs/light-sensor-calibration.md)；
- 标定参数保存于本机控制服务，按 MAC 派生的不可变 `pur-xxxxxxxxxxxx` ID 绑定；串口 MAC 与 MQTT 设备 ID 会归一到同一台设备，固件无需增加标定代码；
- “系统”菜单可导出状态、命令日志与配置备份，并可恢复经过校验的目录配置；
- “诊断工具”的新板入口会自动完成芯片检查、编译、受保护的固件写入校验、启动和 Wi-Fi/MQTT 联网验收；同时提供隔离 MQTT 压力测试和工程报告导出；只有烧录阶段会改变板卡，且安全门槛由控制服务强制执行；
- “帮助”内置系统架构、引脚表、状态灯说明与新板工作流程。

## 后续接入

写入固件会覆盖目标板现有程序，因此工具中心强制要求同板芯片检查、当前源码编译、源码与固件指纹复核，并要求准确输入目标串口确认文字；这一规则不能关闭。芯片检查不写 Flash，但串口握手可能复位板卡；固件编译只生成本机产物。需要万用表、照光或实际净化器响应的步骤只提供明确操作入口，软件不会将未测结果标记为通过。
